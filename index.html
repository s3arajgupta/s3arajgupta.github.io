publications & papers

ARXIV

Deterministic Verification and State Resilience in Asynchronous Multi-Agent Systems

Swaraj Gupta, and Research Collaborators
Preprint on arXiv: Distributed Artificial Intelligence & Multi-Agent Systems, 2025
PDF Code

Autonomous LLM agent architectures often suffer from non-deterministic tool outputs, hallucinated parameter invocations, and cascading state degradation over long horizons. In this work, we propose a formal state-verification layer that enforces deterministic schema validation and transactional rollback across asynchronous agent graphs. Our benchmarks demonstrate a 38% reduction in goal derailment across multi-step technical reasoning tasks while maintaining real-time execution speeds.

Adaptive Layer Partitioning for Memory-Constrained Vector Inference

Swaraj Gupta
Technical Architecture & Benchmark Report, 2024
PDF Code

Dense retrieval pipelines for high-dimensional vector spaces frequently face GPU VRAM saturation during bursty query loads. We present an adaptive memory-tiered layer partitioning technique that dynamically offloads dormant index segments into pinned host memory without sacrificing recall precision or sub-30ms P99 latencies.
